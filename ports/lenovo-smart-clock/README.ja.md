# 初代 Lenovo Smart Clock 向け TECHO5（実験版）

対象は初代 Lenovo Smart Clock CD-24501F（`cube`）です。これは開発中の移植版で、**一般向けに完成したインストーラーや配布イメージではありません**。全機能・全ファームウェア版での動作確認も完了していません。詳しい英語版の記録は [README.md](README.md) を参照してください。

## 確認できたことと、まだ確認が必要なこと

2 台の実機で起動、画面、タッチ、Wi-Fi、音声出力を確認しました。Home Assistant の音声操作、ウェイクワード、Music Assistant / Sendspin、AirPlay、Bluetooth スピーカー、日本語表示も実機で確認しています。短い H.264/AAC 動画は映像と音声を確認しました。これらはすべての動画形式や環境で動作することを保証するものではありません。

Spotify Connect は実機再生未確認です。全機能の網羅試験、全ファームウェア版への対応、完全なバックアップからの復元、起動しないカーネルからの自動復旧も未確認です。カメラなど本機にないハードウェア向けの機能は利用できません。Echo 用のインストーラー、イメージ、OTA 更新は使わないでください。

設定を共通データ領域に保存し、A/B スロット間で引き継ぐ方式を 2 台で試しました。署名付き HTTPS 更新と、意図的に異常を起こした更新からの切り戻しは 2 台目で試験済みです。ただし後者はカーネルと監視処理が起動できる場合の試験です。正式な更新配信先とリリース用署名鍵は未整備で、1 台目の OTA 更新も未試験です。

## 導入について

前提条件、コマンド例、試験起動と通常起動の違いは [詳しい導入手順](INSTALL.ja.md) を参照してください。

現時点で、以下は**開発者向けの作業の流れ**です。必要な純正データの取得、カーネルの再現可能なビルド、アンロック、復旧を含む最初から最後までの手順は完成していません。この説明だけで誰でも安全にインストールできる状態ではありません。書き込みは選択したスロットの内容を上書きします。既存データや復旧方法を確認したうえで作業してください。

1. 所有する対象機器の対応する純正ファームウェアデータを用意します。このリポジトリには純正イメージや抽出済みの独自データは含まれていません。取得方法や異なる純正バージョンへの適合は未整備です。
2. Linux 環境で `tools/extract_stock_firmware.py` を使い、所有者が用意した raw ext4 の vendor パーティションまたは展開済みディレクトリから Wi-Fi／Bluetooth 用ファームウェアを抽出します。タッチ用ファームウェアはこのツールの抽出対象ではありません。
3. `tools/extract_oem_apk.py` で所有者の OEM パーティションから APK を取り出し、`tools/extract_audio_apk.py` と JADX で 2019 年版の音声レジスタ設定を抽出します。抽出物と APK は非公開の作業場所に保管してください。
4. Lenovo の 2019 年公開カーネルソース、外部パッチ、設定およびビルド環境を用意します。`tools/build_cube_kernel.sh` はパッチ適用済みソースを前提とします。パッチの取得・適用やゼロからの再現は未検証です。ルートファイルシステムの作成には、さらに Alpine パッケージやウェイクワードモデルなどが必要です。
5. `tools/build-private-rootfs.sh` に必要な入力を指定して非公開の実験用イメージを作り、`tools/verify_private_rootfs.py` で検査します。検査の成功は実機起動や復旧の保証ではありません。オプションと入力の詳細は各スクリプトと英語版 README を確認してください。
6. 対応するブートローダーの解除済み機器では `tools/install_cube_fastboot.py` が、指定した非アクティブスロットへの試験書き込みと一時起動、その確認後の boot 書き込みを支援します。このツールは設定の共有や自動更新を保証せず、初期状態からの汎用インストーラーでもありません。機器やスロット、イメージを誤ると起動できなくなる可能性があります。

各抽出ツールの入力とオプションは、リポジトリのルートから例えば次のように確認できます。

```sh
python3 ports/lenovo-smart-clock/tools/extract_stock_firmware.py --help
python3 ports/lenovo-smart-clock/tools/extract_oem_apk.py --help
python3 ports/lenovo-smart-clock/tools/extract_audio_apk.py --help
python3 ports/lenovo-smart-clock/tools/verify_private_rootfs.py --help
python3 ports/lenovo-smart-clock/tools/install_cube_fastboot.py --help
```

## ソースと再配布

移植部分のソースと抽出・ビルド用スクリプトを公開しています。Wi-Fi／Bluetooth 用ファームウェアと音声設定には、所有者が用意した純正パーティションを入力します。カーネルは Lenovo の 2019 年公開ソースと外部パッチを使っていますが、ソースの来歴、変更内容、再配布条件の確認は未完了です。TECHO5 側の一部機能では、別途取得する upstream のヘルパーや日本語フォントなども使用します。各入力にはそれぞれのライセンスが適用されます。

純正ファームウェア、抽出した音声データ、機器のバックアップ、認証情報をこのリポジトリに含めない方針です。抽出スクリプトがあること自体は、純正データや生成イメージの再配布権を意味しません。配布する場合は各入力の条件を個別に確認してください。
