# 初代 Lenovo Smart Clock 向け TECHO5（実験版）

[English](README.md) | **日本語**

対象は初代 Lenovo Smart Clock CD-24501F（`cube`）です。これは開発中の移植版で、**一般向けに完成したインストーラーや配布イメージではありません**。全機能・全ファームウェア版での動作確認も完了していません。詳しい英語版の記録は [README.md](README.md) を参照してください。

## 確認できたことと、まだ確認が必要なこと

2 台の実機で起動、画面、タッチ、Wi-Fi、音声出力を確認しました。Home Assistant の音声操作、ウェイクワード、Music Assistant / Sendspin、AirPlay、Bluetooth スピーカー、日本語表示も実機で確認しています。短い H.264/AAC 動画は映像と音声を確認しました。これらはすべての動画形式や環境で動作することを保証するものではありません。

１台で Sendspin の同期が途中でずれる現象を確認しました。時刻測定の間隔より早く時計情報が失効する問題を修正し、その時計に試験適用した後、同期していることを確認しています。長時間再生や再発の有無は引き続き確認が必要で、今回の修正が唯一の原因に対するものかは分かっていません。

Spotify Connect は実機再生未確認です。すべての機能の検証、全ファームウェア版への対応、完全なバックアップからの復元、起動しないカーネルからの自動復旧も未確認です。カメラなど本機にないハードウェア向けの機能は利用できません。Echo 用のインストーラー、イメージ、OTA 更新は使わないでください。

設定を共通データ領域に保存し、A/B スロット間で引き継ぐ方式を 2 台で試しました。署名付き HTTPS 更新と、意図的に異常を起こした更新からの切り戻しは 2 台目で試験済みです。ただし後者はカーネルと監視処理が起動できる場合の試験です。正式な更新配信先とリリース用署名鍵は未整備で、1 台目の OTA 更新も未試験です。

2 台目では Home Assistant の暗号化された `cube_update_now` アクションから実験用イメージを取得し、書き込み、再起動、正常性の確認、ダウンロード済みファイルの削除まで試しました。試験用の配信先と CA はその後削除しています。このアクションは本家の更新カードとは異なり、試験用の検証鍵を組み込んだ場合にのみ使えます。通常のビルドには実験的な OTA 機能や配信先は含まれません。

設定の移行時に使う `cube-shared-migration-guard` は、共通データ領域やネットワーク／SSH が使えない場合に共有設定を無効化して再起動するための任意の保護機能です。有効化には明示的な設定が必要です。正常時の動作は実機で確認しましたが、異常時に元へ戻す経路はまだ実機で検証していません。

## 導入について

前提条件、コマンド例、試験起動と通常起動の違いは [詳しい導入手順](INSTALL.ja.md) を参照してください。

導入は案内付きスクリプトを使います。純正データの取得、解除、起動成功の登録と完全復旧はまだ自動化されていません。書き込みは指定したスロットの内容を上書きします。

`tools/fix_cube_overlay_permissions.py` は、古い試作版で問題があったシステムファイルの所有者と権限を確認できます。`--apply` は実行中の対象ルートとスロットを確認したうえで修正しますが、もう一方のスロットや共有データには変更を加えません。`tools/update_daemon_ssh.py` は、SSH を設定済みの開発用端末でデーモンだけを手動更新するツールです。どちらも OTA や完全な復旧手段ではありません。

実験的な共通データや更新機能は、対応する診断バイナリや明示的なビルド設定が必要です。`CUBE_SHARED_DATA=1` は共通データへの移行を有効にし、`CUBE_BLUETOOTH=1` は試験済みの Bluetooth ブリッジを有効にします。実験用署名付き更新には `CUBE_UPDATE_PUB` と `cube_update_trial` タグ付きの診断バイナリが必要で、`CUBE_UPDATE_WATCH=1` は起動時の監視を有効にします。これらだけで正式な更新配信は構成されません。署名ツール `tools/cube-update-sign` の鍵は Git 管理外で保管してください。故障を意図的に起こす試験設定は配布版に使わないでください。

## ソースと再配布

移植部分のソースと抽出・ビルド用スクリプトを公開しています。Wi-Fi／Bluetooth 用ファームウェアと音声設定には、所有者が用意した純正パーティションを入力します。カーネルは Lenovo の 2019 年公開ソースと外部パッチを使っていますが、ソースの来歴、変更内容、再配布条件の確認は未完了です。TECHO5 側の一部機能では、別途取得する upstream のヘルパーや日本語フォントなども使用します。各入力にはそれぞれのライセンスが適用されます。

実験用の `tools/build_cube_kernel_from_source.py` は、Lenovo の公開ソース、固定した参照パッチ、コンパイラーを取得し、所有者の 2019 年版純正 boot から設定を取り出してカーネルをビルドします。この新しい経路をクリーンな環境から実機導入まで通して確認する作業と、参照パッチや生成カーネルの配布条件の確認は未完了です。

純正ファームウェア、抽出した音声データ、機器のバックアップ、認証情報をこのリポジトリに含めない方針です。抽出スクリプトがあること自体は、純正データや生成イメージの再配布権を意味しません。配布する場合は各入力の条件を個別に確認してください。
